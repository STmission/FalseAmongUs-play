# 伪人迷局 · 望月废校（网页试玩）

[直接开始游戏](https://STmission.github.io/FalseAmongUs-play/)

默认使用性能画质，可在场景内切换细节画质。当前为单人开发试玩：一名玩家与十一名职业NPC、第一／第三人称切换、废校探索、身份推理、职业对话、零食恢复体力和四日流程。美术与完整剧情仍需打磨，真人联机、微信和iOS完整版继续开发。

推荐电脑浏览器，首次载入需下载3D资源。点击“单人剧情”进入；WASD移动、右键拖动视角、Shift冲刺、E交流、V切换视角、F身份技能、R使用工具、Esc菜单。右上角可退出对局。手机横屏使用触控按钮；尚未完成全部手机适配验收。

本仓库保存可部署的静态构建与许可记录，后续试玩更新将在这里发布。发布版本：web-playtest-2026-10-07.3。反馈请提交Issues并附设备、浏览器和重现步骤。
